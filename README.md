# Telegram Notification Bot

Запуск: установите зависимости через `./install.sh` (скрипт можно запускать из любой директории; создаётся виртуальное окружение `.venv`), укажите токен в `TELEGRAM_TOKEN.txt`, затем выполните `./start.sh`. Для проверки работы фона используйте `./start.sh status` (покажет наличие screen-сессии и последние строки лога).

Подробная документация находится в файле `BOT_DOCS.md`.
