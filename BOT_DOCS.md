# Telegram Notification Bot

 Этот бот написан на Python с использованием `python-telegram-bot` и предназначен для рассылок погоды, курсов валют, расписания групп и персональных напоминаний.
 Главное меню на кнопках минимизирует ручной ввод — базовые действия доступны без ввода команд.

## Основные функции
- Регистрация пользователя при /start с сохранением идентификатора.
- Настройка города с автоподбором часового пояса (через Open-Meteo Geocoding API).
- Выбор учебной группы с валидацией по заранее заданному списку (регистр не важен).
- Настройка ежедневной рассылки: время и формат расписания (день или неделя).
- Получение погоды сейчас и краткого прогноза на день.
- Получение курсов USD/RUB, USD/CNY и BTC/USD.
- Сбор и кеширование расписаний групп с сайта `https://lk.tolgas.ru/public-schedule/search/`.
- Создание напоминаний с выбором даты и времени (кнопки +5/30 минут, -5/30 минут или ручной ввод). Проверка на прошедшие даты/время.
- Хранение пользователей, профилей, напоминаний и кеша расписаний в JSON-файлах.
- При рестарте бот восстанавливает задачи и отправляет просроченные напоминания с пометкой о задержке.

## Структура проекта
- `bot/`
  - `bot_app.py` — основной код бота, обработчики команд и задач.
  - `data_manager.py` — работа с JSON файлами (пользователи, профили, напоминания, кеш расписаний).
  - `groups.py` — список допустимых групп и нормализация регистра.
  - `reminder_service.py` — сохранение и планирование напоминаний, учёт часовых поясов.
  - `schedule_parser.py` — парсинг расписания и кеширование.
  - `weather_currency.py` — получение геоданных, погоды и курсов валют.
- `data/` — директория для JSON-хранилищ (создаётся автоматически при записи).
- `TELEGRAM_TOKEN.txt` — файл для токена бота (заполните своим ключом).
- `requirements.txt` — зависимости Python.
- `install.sh` — скрипт установки зависимостей (Ubuntu 24.04).

## Формат хранения данных
- `data/users.json` — список ID пользователей.
- `data/profiles.json` — список профилей `{user_id, username, city, timezone, group, broadcast_time, broadcast_scope}`.
- `data/reminders.json` — список напоминаний `{id, user_id, message, send_at_local, send_at_utc}`.
- `data/schedule_cache.json` — кеш расписаний вида `{group: {date: [lessons...]}}`.

## Основные команды
- `/start` — регистрация и подсказка по настройке.
- `/profile` — показать текущие настройки профиля.
- `/setcity` — указать город (определяется часовой пояс).
- `/setgroup` — выбрать группу из списка (регистр не имеет значения, ошибки подсвечиваются).
- `/setbroadcast` — выбрать время рассылки и охват расписания.
- `/broadcast` — краткая инструкция по настройке рассылки и кнопка «Сообщение сейчас» для мгновенной отправки подборки.
- `/reminder` — просмотр активных напоминаний и создание нового через кнопку.
- `/new_reminder` — прямое создание напоминания.
- `/help` — список команд.
- `/cancel` — отмена текущего диалога.
- `/menu` — открыть главное меню-клавиатуру (аналог /start).

## Описание модулей
- **`NotificationBot` (bot/bot_app.py)**
  - Регистрация обработчиков команд и диалогов.
  - Настройка расписаний ежедневных рассылок по часовому поясу пользователя.
  - Сбор погодных данных, курсов и расписаний перед отправкой рассылки.
  - Управление напоминаниями через `ReminderService`.
- **`ReminderService` (bot/reminder_service.py)**
  - Сохранение/удаление/загрузка напоминаний из JSON.
  - Перевод локального времени пользователя в UTC с учётом часового пояса.
  - Восстановление отложенных задач при старте бота и отправка просроченных сообщений.
- **`ScheduleParser` (bot/schedule_parser.py)**
  - Парсинг таблицы расписания с сайта колледжа.
  - Кеширование расписаний по группам, форматирование вывода (день или неделя).
- **`WeatherService` (bot/weather_currency.py)**
  - Геокодирование города, получение текущей погоды и краткого прогноза.
- **`CurrencyService` (bot/weather_currency.py)**
  - Получение курсов USD/RUB, USD/CNY и BTC/USD.
- **`data_manager` (bot/data_manager.py)**
  - Безопасная запись JSON (атомарно), автосоздание файлов и каталогов.

## Настройка и запуск
1. Установите зависимости: `./install.sh` (можно запускать из любой директории; создаёт виртуальное окружение `.venv` рядом со скриптом и при необходимости подтянет python3/pip3/screen через apt).
2. Добавьте токен Telegram в `TELEGRAM_TOKEN.txt` (без лишних пробелов).
3. Запустите бота фоном: `./start.sh` (использует `.venv` и создаёт screen-сессию `telegram_notification_bot`; для подключения используйте `screen -r telegram_notification_bot`).

## Расширения и оптимизации
- При необходимости можно вынести API-ключи погоды/курсов в переменные окружения.
- При увеличении нагрузки кеш расписаний можно обновлять по крону и использовать lock-файлы.
- Для админ-панели можно использовать отдельный модуль, который обновляет `data/users.json`.
